# ServeConnect — Web Dashboard

The administration and leadership console for ServeConnect (React 19 + TypeScript + Vite).

Rules for working on this project: [`CLAUDE.md`](CLAUDE.md) (and the repo-wide [`../CLAUDE.md`](../CLAUDE.md)).

```bash
npm install
npm run dev     # local dev server
npm run build   # type-check + production build
npm run lint    # oxlint
```
